# Build

```sh
python3 scripts/build.py waveshare/esp32-s3-touch-amoled-2.06
```

The older 1.85C source remains but needs a fresh physical recheck before
release. Build one watch at a time: both use `build/` and `sdkconfig`. The manufacturer
prefix is required. Before flashing, check the generated `sdkconfig` for the
matching `CONFIG_BOARD_TYPE_...=y` line and confirm `build/xiaozhi.bin` was
created by the latest build. The language menu remains es-ES with en-US fallback.

The 2.06 watch has 32 MB of flash. For now it uses the same partition positions
as the 1.85C build, so the upper half of its flash is unused. The build still
reports the correct physical 32 MB flash size.

## Traps

- **A previous image can remain in `build/` after a failed build.** Check the
  latest log for `Project build complete` and no `[ERROR]` or `FAILED:` lines,
  and verify the generated `sdkconfig` names the chosen watch.
- New `.ogg` assets need the language header regenerated by hand; see [Sounds](../runtime/sounds.md).

## Output

A successful build produces `build/merged-binary.bin` plus the individual images (`xiaozhi.bin`, bootloader, partition table) and `build/flash_args` for esptool.
